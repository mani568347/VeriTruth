Privacy Policy

Last Updated: May 2026 • Platform Information Safeguard Standards

1. Information Logging

To maintain security and functionality across the news verification registry, the system logs authentication details, submitted payload text/URL routes, and technical diagnostics.

2. Data Encryption & Storage

User credentials are stored using industry-standard password hashing schemes. Historical verification query records are stored in protected database tables linked to the authorized user account. Payloads are processed transiently for model evaluation.

3. Third-Party Integrations

Authentication via Google SSO utilizes OAuth protocols directly hosted by Google. VeriTruth does not view or store Google passwords. Context calculations communicate with API services (such as Groq AI explainer models) over encrypted pathways.
